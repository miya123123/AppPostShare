# プチプチ無限クラッシュ

なぞって、潰して、もう一回。30秒でどこまで稼げる？

## ゲームについて
指やマウスでプチプチを連続で潰す、30秒のスコアアタックを楽しむ気分爽快系ゲームです。小粒でコツコツ稼ぐか、巨大粒で一気に得点するか。短い時間の中で判断しながら、ハイスコアを目指しましょう。

## 遊び方
- スマートフォン：タップ、または指でなぞって潰します。
- パソコン：マウスを押しながらドラッグします。
- キーボード：プレイ領域を選び、矢印キーで移動、スペース／Enterで潰します。
- 最初にプレイ領域を操作すると30秒のカウントダウンが始まります。

## 小粒も、巨大粒も、全潰しも
- 小粒は＋1点。巨大粒は＋15点、潰した数は10個分！
- 全て潰すとボーナス＋15点。演出後、自動で次のシートへ進みます。
- 全潰しの演出中はタイマーが一時停止します。

## インク爆弾にご用心
巨大粒には、見た目で分からないインク爆弾が潜んでいます。インクが飛び散ったら、周辺をなぞって拭き取りましょう。拭き取り中も時間は進みます。

「シート交換」なら得点と残り時間を引き継いで、インクも一掃できます。ただし、交換したシートの全潰しボーナスは獲得できません。

## 対応環境・設定
ブラウザでプレイできます。ゲーム内UIは日本語です。効果音はON／OFFを切り替えられます。振動は対応端末・ブラウザで利用できます。時間切れ後は「もう一度遊ぶ」で再挑戦できます。

ダウンロード版はZIPを展開し、index.htmlをブラウザで開いてください。インストールは不要です。

## 制作について
AIの支援を受けて開発しました。ゲーム内の描画はCanvas 2D、効果音はWeb Audio APIで生成しています。


ゲームv3ではプレイ中の「ゲームをリスタート」でスコアと時間を初期化します。
