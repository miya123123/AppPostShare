## スクリーンショットの撮影

公開済みのdev-v13を共有Chromeで開き、実際にプレイして撮影しました。

撮影元: https://zipper-world.miya333.chatgpt.site/

ページタイトル: ファスナー・ワールド 開発版 dev-v13 | Zipper World

撮影日: 2026年11月11日（日本時間）

Spaceと方向キーで引き手を操作し、撮影の合間にゲーム標準の一時停止を使用しました。庭・都市・海を詰まらずに開いて虹色フィーバーへ到達し、その後の星の遊園地ではお宝ルートを選んでいます。

ゲームコードや内部状態の書き換えは行っていません。タイマー・スコア・倍率・摩擦ゲージはブラウザーが実際に表示していたものです。PNGは撮影済みのページ全体画像からプレイ領域を切り出したもので、UIの描き足し、画面の生成、景色の差し替えは行っていません。撮影時点の進行率は庭89%、都市88%、海88%、星87%、虹色フィーバー86%です。

## 起動制限の調査結果

1. 最初のPlaywright起動では、Playwrightが期待するバージョンのheadless-shell実行ファイルが見つかりませんでした。
2. インストール済みの `/usr/bin/chromium` を指定すると、起動管理処理の `ProcessSingleton` で `socket() failed: Operation not permitted` が発生しました。
3. コマンド実行環境で個別に確認すると、AF_UNIXのソケット作成はerrno=1（Operation not permitted）で拒否され、AF_INETのソケット作成は成功しました。プロセスではSeccompモード2とNoNewPrivs=1が有効でした。拒否した個別のセキュリティルールまでは特定していません。
4. 共有ブラウザー自体は利用可能でしたが、ローカルHTMLを `file:` で開く操作はURLポリシーで拒否されました。
5. メモに記載されていた公開済みのHTTPS版dev-v13は共有ブラウザーで正常に開けました。同じChromeの対象タブをデスクトップへ表示し、ネイティブのキーボード入力でプレイ・撮影できました。

結論: 前回の主な停止箇所は、コマンド実行環境によるUNIXソケット作成の拒否です。ゲームの描画不具合ではなく、実行経路に依存する制限でした。今回は公開済みHTTPS版を正常に表示できる共有ブラウザーで撮影を完了しました。
