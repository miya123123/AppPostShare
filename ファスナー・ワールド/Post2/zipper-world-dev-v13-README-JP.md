# ファスナー・ワールド — dev-v13

灰色の景色に付いたファスナーを引き、カラフルな世界を開く30秒のスコアアタックゲームです。

対象バージョン: **dev-v13**  
更新日: **2026-11-05**  
比較元: 現行Sites公開版 **v12**（公開ページの配布ソースとの比較）

## 起動と配布物

`zipper-world-dev-v13.html` をブラウザで開くと遊べます。インストール、ビルド、通信、外部画像は不要です。

- `zipper-world-dev-v13.html`: HTML / CSS / 操作 / 描画 / スコアの全ソース。
- `zipper-world-dev-v13-README-JP.md`: この説明書。
- `world-images-dev-v13/`: 開いた状態の7ワールドの背景PNG。各900×1080ピクセルです。ゲーム画面のHUD・ファスナー・操作UIを含まない、描画コードから書き出した景観画像です。

## 操作

- 「世界をひらく」を押して開始します。
- 金色の引き手を指やマウスでつかみ、点線に沿って下へドラッグします。
- 分岐では、緑の安全ルートか金のお宝ルートを選びます。
- 途中で指を離しても、同じ引き手から再開できます。
- 通常世界では、正確にルート上を引いていても高速操作で摩擦が増えます。ルート外の移動でも摩擦が増えます。
- 摩擦100%で詰まります。指を離すと冷却し、20%以下で復帰します。摩擦ゲージはゲーム画面の真下にあります。
- キーボードはSpaceでつかむ・離す、矢印キーまたはWASDで移動、Escapeで一時停止します。
- 画面右下は一時停止、右上はサウンド切替です。

## スコアと進行

- 進行スコア: 各世界につき最大300点 × 倍率。
- 開放ボーナス: 安全200点、お宝700点、虹色フィーバー600点。それぞれ倍率を掛けます。
- お宝の開放ボーナスは、安全の3.5倍です。進行点を含めた総得点の倍率ではありません。
- 世界開始から3.5秒以内に詰まらず開放すると、次の世界の倍率が＋0.5。最大5倍です。
- 条件を満たさない開放では次の世界で1倍に戻り、詰まるとその場で1倍に戻ります。
- 通常世界を詰まらず3連続で開くと、次に虹色フィーバーが始まります。フィーバー中は摩擦がありません。
- 通常世界は、庭 → 街 → 海 → 宇宙の順に進み、周回でカーブが少し増えます。
- 虹色フィーバーでは7世界を全画面に1つずつ順番に表示し、短いフェードでつなぎます。
- 通常の開放演出は約0.9秒、フィーバーのフィナーレは約1.3秒です。開放演出中はタイマーが止まります。

## 現行Sites v12からdev-v13への更新点

Sites v12と開発版dev-v12は別の版番号です。以下は公開中Sites v12からdev-v13までの累積差分です。公開Sitesへの反映状況を示すものではありません。

### リスクとリターン

| 項目 | Sites v12 | dev-v13 | 変化 |
| --- | --- | --- | --- |
| ルート内の高速前進による摩擦係数 | 0.24 | 0.30 | 同条件で1.25倍 |
| ルート外の摩擦係数 | 0.37 | 0.333 | 同条件で0.9倍 |
| お宝ルートの開放ボーナス | 600点 × 倍率 | 700点 × 倍率 | 100点 × 倍率増加 |

ルート内の摩擦は、`clamp((pullSpeed - 600) / 1200, 0, 1) × 0.30` を前進距離に掛けます。毎秒600ゲーム座標を超える速度で増え始め、毎秒1800で速度による係数が上限になります。

ルート外の摩擦増加は `移動距離 × 0.333 × (1 + カーブ量 × 0.4)` です。上表は係数の比較であり、実際の増加量は距離・速度・カーブ量に依存します。

安全ルートの開放ボーナス200点とフィーバーの開放ボーナス600点は継続しています。画面内のお宝ルートの説明も700点・安全の3.5倍に更新しています。

### 摩擦ゲージとスマートフォン表示

- ガイド内の摩擦ゲージをゲーム画面の真下へ移動しました。
- ゲージの太さやラベルサイズを調整し、プレイ中に確認しやすくしました。
- スマートフォンでは画面高に応じてゲーム画面を縮め、直下のゲージも確認しやすい配置にしました。

### ワールド景観

- **World1 / しずくの庭**: 川の水面・岸を共通の形状で連続させ、流れの線を縦方向へ調整しました。道路を川岸と橋につなげ、建物・植物の配置を整理しました。白色で厚みのあるカモメ5羽を追加しています。右側の表示調整後の配置は前の開発版の配置へ戻しています。
- **World2 / ネオン・シティ**: 道路の中央線を点線に統一し、遠近感に沿う連続した軸上へ配置しました。道路の色と両端の線も調整しています。
- **World3 / サンゴの海**: 海底のヒトデの配置・大きさ・影を調整し、上部に柔らかな水中光の曲線を追加しました。
- **World4 / 星の遊園地**: 浮遊島付近の光と建物下のハイライトを追加しました。
- **World5 / 水晶洞窟**: 水晶の足元に地下湖を描き、配置・反射・発光を調整しました。上部の繰り返しの折れ線は、数を絞った先細りの曲線状の光跡へ変更しました。
- **World6 / お菓子の森**: キャンディーが中央の道を覆いにくい配置にし、奥行きに応じた大きさ・影・描画順を調整しました。
- **World7 / オーロラの空島**: 島の表面と岩肌の線を洗練させました。3つの島に家を配置し、島間を結ぶ吊り橋2本を追加しました。滝や光の表現も追加しています。

カモメ5羽は背景の描画データ上の数です。今回の配布準備では、実機での開放時に5羽すべてが見えることの再検証は行っていません。

### デバッグ機能と版表示

- ヘッダーの「🌈 虹色へ」ボタン、専用スタイル、強制フィーバー開始処理とイベント登録を削除しました。
- 通常プレイで3連続成功すると始まる虹色フィーバーは引き続き利用できます。
- HTMLのタイトルとフッターにdev-v13を表示し、配布するHTML・Readme・PNG・ZIPのファイル名にもdev-v13を付けています。
- SitesのソースZIPへのフッターリンクは、開発版のバージョン表示に置き換わっています。この配布ZIPには単独で起動できるHTMLを収録しています。

## 画像・サウンド・保存

景観・建物・植物・引き手・粒子はCanvas 2Dの描画コードで生成します。配布PNGはその景観描画から書き出したもので、ゲームの実行には不要です。画像生成モデルは使用していません。

サウンドはWeb Audioの合成音です。初期状態はオフで、右上ボタンからオンにできます。ベストスコアと音設定はブラウザ内に保存します。OSの動きを減らす設定にも対応しています。

## 調整する場所

HTML内の `zipper-core` にゲーム処理があります。`makePath` はルート、`Engine.reset` は制限時間、`Engine.move` は摩擦と進行点、`Engine.complete` はボーナス・倍率条件です。

`zipper-app` 内の `scene` が7ワールドの描画です。通常世界は先頭4テーマを使い、虹色フィーバーでは7テーマを使います。
