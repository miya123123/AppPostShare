【ひらく、庭】公開しました！

# 作業内容
言葉のない、触って、試して自然に遊び方を理解できるよう設計したゲーム【ひらく、庭】の試作版を公開しました。
エンディングにはわりとこだわりました！


触って、試して、偶然できた。発見するたびに広がる、言葉のない小さな庭です。

小庭から草原へ、小川の先の奥庭へ。木の実を運び、キノコで跳ね、ウサギと遊びながら、庭の小さな変化を見つけていきます。通常のゲーム画面では、文字・数字・矢印による説明を使いません。時間制限やスコアはありません。

| やりたいこと | タッチ・マウス | キーボード |
| --- | --- | --- |
| 地面へ移動する | 地面をタップ／クリック | WASD・方向キー |
| 連続して移動する | 画面をドラッグ、または左下のスティック | WASD・方向キーを長押し |
| 仕掛けに近づいて触れる | 仕掛けをタップ／クリック | 近づいてSpace・E |
| 近くのものに触れる | 右下の手のボタン | Space・E |
| 木の実を拾う／置く | 木の実をタップ、または近くで手のボタン | Space・E |
| 庭を見渡す | 左上の花のボタン | ボタンへフォーカスして操作 |
| ヒントを切り替える | 花の隣の、光を宿す石のボタン | ボタンへフォーカスして操作 |
| 音を切り替える | 右上の音のボタン | ボタンへフォーカスして操作 |
| 最初からやり直す | 右上の芽のボタンを約1.5秒長押し | 芽のボタンへフォーカスし、Space・Enterを長押し |
| エンディングから庭へ戻る | 下部の花のボタン | Escape、または花のボタンを操作 |
