# ひらく、庭。

触って、試して、偶然できた。発見するたびに広がる、言葉のない小さな庭です。

小庭から草原へ、小川の先の奥庭へ。木の実を運び、キノコで跳ね、ウサギと遊びながら、庭の小さな変化を見つけていきます。通常のゲーム画面では、文字・数字・矢印による説明を使いません。時間制限やスコアはありません。

## はじめに

ソースZIPを展開し、`hiraku-garden` フォルダーで次のコマンドを実行します。Python 3を使用します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザーで <http://127.0.0.1:8000> を開くと遊べます。終了はターミナルで `Ctrl+C` です。Windowsで `python3` が見つからない場合は、インストール済みのPython 3のコマンド（例：`py -3`）に置き換えてください。

`index.html` の直接ダブルクリックではなく、HTTPサーバーから開いてください。ゲームはJavaScriptのES Modulesを使います。ゲームを遊ぶためのビルドや `npm install` は不要です。

別の静的ホスティングへ配置する場合は、`dist/` の内容を同じ階層関係で配信します。バックエンドやAPIキーは使用しません。

## 操作

| やりたいこと | タッチ・マウス | キーボード |
| --- | --- | --- |
| 地面へ移動する | 地面をタップ／クリック | WASD・方向キー |
| 連続して移動する | 画面をドラッグ、または左下のスティック | WASD・方向キーを長押し |
| 仕掛けに近づいて触れる | 仕掛けをタップ／クリック | 近づいてSpace・E |
| 近くのものに触れる | 右下の手のボタン | Space・E |
| 木の実を拾う／置く | 木の実をタップ、または近くで手のボタン | Space・E |
| 庭を見渡す | 左上の花のボタン | ボタンへフォーカスして操作 |
| ヒントを切り替える | 花の隣の、光を宿す石のボタン | ボタンへフォーカスして操作 |
| 音を切り替える | 右上の音のボタン | ボタンへフォーカスして操作 |

近くに対象がない状態で手の操作をすると、プレイヤーが軽く跳ねます。全画面ボタンは対応するブラウザーで表示します。音は最初のタッチやキー操作の後に再生されます。

## 庭の仕掛け（ネタバレを含みます）

左上の花の8枚の花びらは、次の8種類の発見を表します。複数のベル・キノコ・花壇は、それぞれ同じ種類の発見にまとまります。

| 発見 | できること・起こること |
| --- | --- |
| はじまりの花 | 触れると小庭の入口が開き、草原へ進めます。 |
| 木の実の花 | 木の実を植え床へ運ぶ、または転がすと花が咲きます。 |
| 風のベル | 触れて音を鳴らします。ウサギも音に反応します。 |
| キノコジャンプ | プレイヤーが跳ねたり、持った木の実をキノコの上で弾ませたりできます。大きなキノコは小川の先へ進む手段にもなります。 |
| 丸太の橋 | 丸太に触れると橋が架かり、奥庭へ行き来できます。 |
| 水の波紋 | 水に触れる、または木の実を入れると波紋が広がります。水場のキノコからは、開花と蝶につながる連鎖も起こせます。 |
| 眠る石 | 3回触れると、不思議な生き物が目覚めます。 |
| 大きな木 | 触れると光と音で応えます。8種類すべてを発見した後には特別な演出が続きます。 |

鉢を開いたり、ウサギをなでたりする寄り道もあります。これらは8種類とは別の遊びです。

### 木の実を運ぶ・弾ませる

木の実を拾うと両手で持ち、歩いて運べます。持っている間は植え床を通っても勝手に植わりません。植え床のそばで置くと育成に使えます。地面へ置いた木の実を体で押して転がすこともできます。

水場以外の大小2つのキノコでは、持った木の実を上へ置くと3回バウンドし、近くの地面へ着地します。水場のキノコでは木の実が水へ飛び、波紋、開花、蝶へと反応がつながります。木の実は再び使えます。

### ウサギと遊ぶ

ウサギは木の実を追い、鼻で押したり、持った木の実についてきたりします。タップして近づくとなでることもできます。

近くでプレイヤーがキノコジャンプをすると、ウサギは木の実遊びより優先して、そのキノコまで歩きます。傘に乗ってからジャンプし、安全な地面へ着地して休みます。遠くにいる場合は反応しません。

### 生き物によるヒント

ヒントは初期状態でOFFです。ONにすると、近づいた未発見の仕掛けに光や生き物が自動で反応します。石の目覚め前は淡い光、目覚めた後は不思議な生き物が案内役です。

ON／OFFは切り替えるまで維持し、再読み込みや「最初からやり直す」後も保持します。対象から離れたとき、発見したとき、持ち物が変わったときは案内先を見直します。発見済みの仕掛けにはヒントを出しません。OFFでは対象へのヒント反応を止めます。

## 大きな木とエンディング

木への通常の接触では約2.8秒の短い返事があります。全8種類を発見して木へ触れると、初回は約10秒の演出からエンディングへ続きます。花、キノコ、ベル、波紋が順に応え、光が木を包みます。木の返事の間は操作でき、エンディングに切り替わると通常の遊びを一時停止します。

エンディングでは8色の花びらが根元の一輪へ集まり、その周囲やプレイヤーの足元にも数十輪の花が開きます。太めの虹と木漏れ日が広がり、満開の後はウサギが走って跳ね、不思議な生き物が花畑を巡ります。「庭に戻る」を押すまで眺められます。途中で戻ることもできます。

**エンディングで進行はリセットしません。** プレイヤーの再開位置は、エンディングへ入る直前の位置です。木のそばに見える人物・ウサギは演出用のコピーで、実際の位置を動かしていません。木の実の配置と所持状態も維持します。

エンディングへ入った記録のあるデータでは、根元の花と周囲の花が通常の庭にも残ります。再読み込み後や体験済みの既存セーブでも表示します。花は移動や仕掛けの操作を妨げません。虹や特別な光はエンディング用の演出です。

エンディング中に閉じて再度開いた場合も、保存した位置と進行で通常の庭を再開します。エンディングの自動再生はしません。その後の木への接触は短い返事になります。

## 自動保存とやり直し

進行はブラウザーの `localStorage` に自動保存します。発見、開いたエリア、花壇、石、鉢、プレイヤーとウサギの位置、木の実の配置と所持、エンディングの体験記録を保持します。音とヒントの設定は進行とは別に保存します。ジャンプ中の保存からは、安全な地面へ復元します。

| 保存キー | 内容 |
| --- | --- |
| `hiraku-garden-v1` | 庭の進行と配置 |
| `hiraku-garden-sound` | 音のON／OFF |
| `hiraku-garden-hints` | ヒントのON／OFF |

保存先はブラウザー・プロファイル・サイトの配信元ごとに分かれます。公開サイトとローカル実行の進行は別々です。端末間の同期やセーブのインポート／エクスポート機能はありません。サイトデータを削除すると保存内容も失われます。

芽のボタンを約1.5秒長押しすると、庭の進行と配置、エンディング後の花を初期状態へ戻します。音とヒントの設定は保持します。長押しの途中で離す、ボタンから外れる、Escape、フォーカス喪失などで取り消せます。

## テスト用デバッグ画面

右上の道具のボタンから開きます。この画面内にはテスト用の文字を表示します。

- 8種類の仕掛けを「すべて／未完了／完了」で絞り込みます。
- 「場所を見る」で、未開放の場所も含めて位置を確認できます。
- 各行の「完了にする／未完了に戻す」で状態を変更し、即時保存します。
- 画面を開いている間は通常のシミュレーションを停止します。

変更してもプレイヤーや木の実を移動させず、すでに開いた通路を閉じません。木の実の花を未完了にすると花壇を未開花へ、水を未完了にすると水やりと連鎖の花を解除するなど、再テストに必要な状態も調整します。

**エンディングを再確認するには**、他の7種類を完了にしたうえで「大きな木」を未完了に戻し、画面を閉じて木へ触れます。これにより木の特別演出とエンディングを再体験できます。木を未完了に戻す操作は、エンディングの体験記録と、その記録による花の表示も解除します。完了への変更だけではエンディングを自動再生しません。

デバッグを簡単に無効化するには、`dist/garden-debug.js` 冒頭の `DEBUG_ENABLED` を `false` にします。ボタン、画面、専用CSSの読み込みが無効になります。処理と見た目は `garden-debug.js` と `garden-debug.css` にまとめています。

## 技術構成と素材

HTML・CSS・JavaScriptによる静的Webゲームです。景色、キャラクター、花、光はCanvas 2D、操作アイコンはインラインSVG、音はWeb Audio APIでプログラムから生成します。

画像生成AI、外部の画像・フォント・録音素材は使用していません。実行時の外部ライブラリーやサーバー側の依存パッケージもありません。

OS・ブラウザーの「動きを減らす」設定（`prefers-reduced-motion`）を参照し、カメラ移動、花びらの移動、エンディング後半の走行・跳躍・周回などを抑えます。

## 自動テスト

Node.jsの標準テストランナーを使います。確認環境はNode.js v24.22.1です。依存パッケージのインストールは不要です。

```sh
npm test
```

または次のコマンドで実行できます。

```sh
node --test tests/*.test.js
```

現在のテストは74件です。移動、開放ルート、木の実、ウサギ、キノコの優先動作、連鎖、保存と復元、やり直し、ヒント、デバッグ、エンディング、花の保持、動きを減らす設定を確認します。

テストはゲームロジックと模擬DOMでの操作を対象にしています。実際のブラウザーでの描画や音、端末固有の操作感は、これとは別に確認する必要があります。

## 配布ZIPを作り直す

ソースやREADMEを編集した後、プロジェクトのルートで実行します。

```sh
python3 scripts/package_source.py
```

`dist/downloads/README.md` と `dist/downloads/hiraku-garden-source.zip` を生成します。ZIPにはゲームの全静的ソース、README、設計書、テスト、パッケージ用スクリプト、SHA-256一覧をまとめます。Gitの履歴、ホスティングの識別設定、実際のセーブデータは含めません。ダウンロード用のZIP自身を再帰的に取り込むこともありません。
