# 透明スライム素材メーカー 🟢

泡・宝石・星が浮かぶ、柔らかい透明スライムの素材生成ツールです。設計書に沿って、輪郭・体内の飾り・屈折模様・光沢を分けて実装しています。

## 起動

`transparent-slime-studio.html`をブラウザで開いてください。インストールやサーバーの準備は不要です。サイト用の同じファイルは`dist/index.html`です。外部ライブラリや画像素材を読み込まず、ローカルでも使えます。

## 使い方

1. ミントゼリー・アクアクリスタル・星くず・ピーチから素材プリセットを選びます。
2. ぷにぷに・まんまる・しずく・とろりから形を選びます。
3. 色・透明度・ふくらみ・光沢を調整します。
4. 泡（0〜50個）・宝石（0〜12個）・星（0〜20個）を好きな数だけ浮かべます。
5. 必要に応じてシードを入力して「適用」を押します。「別のスライム」で新しいシードを作れます。
6. PNGサイズを512・1024・2048pxから選んで「透明PNGで保存」を押します。

プレビュー背景は透明・白・暗色に切り替えられます。背景はPNGに含まれません。プレビューをタップするとぷるんと揺れます。画像の模様や配置は揺れても変わりません。

## 同じ素材を再現する

シードと、形・色・透明度・ふくらみ・光沢・飾りの数をそろえると、同じ配置のスライムを再現できます。シードは40文字まで。出力サイズを変えても、形や飾りの配置は共通です。設定値は画面を開いている間保持されます。

## 透明PNGについて

画像の外側は完全に透明です。本体は半透明で、泡・宝石・星・ハイライトには個別の透明度があります。透明度スライダーを高くすると体内がよく透け、光沢の設定で縁や反射の輝きを調整できます。

高解像度の画像は保存時に再描画します。保存中はボタンに進行状態を表示します。生成した素材はゲームのキャラクター、パズルピース、アイコン、ステッカーなどに使えます。

## 実装の構成

- HTML / CSS / JavaScript / Canvas 2Dによる単一HTML。
- ガウス型メタボールの密度場から輪郭を生成。
- 密度の勾配による表面法線、厚み、縁の濃淡、反射光。
- シード付き乱数による泡・宝石・星の配置と、内部マスクによるクリップ。
- 2Dでの屈折模様と色のベールによる、飾りの奥行き表現。
- メタボールのガウス関数を縦横に分離し、描画処理を軽量化。
- プレビュー640px、PNG出力512 / 1024 / 2048px。
- 対応ブラウザではWebMCPの設定取得・素材調整ツールを登録。

`slime-engine`のスクリプトが生成処理、`slime-app`のスクリプトが編集UIと保存処理です。設計書と検証内容は同梱のMarkdownをご覧ください。


## 顔・表情（追加）
顔表示は初期OFF。目3種類、口3種類＋口なし。上下位置・大きさ・目の間隔・色を調整できます。顔は最前面で輪郭にクリップし、全PNGサイズに反映します。シード・プリセット変更時も顔設定を維持します。


## プレビュー固定と即時反映
上部固定は初期OFF。固定中は上部にコンパクト表示し、表示高さ分の余白を確保します。固定解除はプレビュー内でも可能です。設定変更は待ち時間を置かず次の描画フレームで反映し、連続操作は最新値にまとめます。操作時の描画は480px、PNG保存は指定解像度で描画します。


## ぷるぷる常時再生
プレビュー内の再生ボタンでループ開始／停止。初期停止。横揺れ・伸縮・回転を表示変形のみで実行。停止は320msで通常形へ戻ります。設定変更・固定表示中も継続し、再生中のタップ揺れは抑制します。PNGは通常形で保存します。


## 目と口の上下間隔
「目と口の上下間隔」スライダー（40〜200%、初期値100%）で、目の位置を基準に口の縦位置を調整します。プレビューおよび透明PNGに反映され、顔設定とともにプリセット切り替えでも維持されます。


## 拡大プレビュー
プレビュー領域をタップ／クリックすると、同じ設定・背景で拡大ダイアログを表示します。閉じるボタン、背景タップ、Escapeで終了し、フォーカスは元のプレビューへ戻します。拡大表示のスライムをタップすると単発で揺れ、常時再生中は拡大側も同時に揺れます。固定表示・透明PNG出力との併用に対応します。
