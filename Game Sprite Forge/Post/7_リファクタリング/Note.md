# 概要
スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」の開発記録です。
大規模なリファクタリングを行いました。
ファイルの分割、アクセシビリティやデザインの改修などを行いました。
今後は、出品に向けた準備や、リファクタリングの継続を行います。

# 作業内容
既存の単一HTMLファイルに対し、以下のリファクタリングを行いました（優先度大）。

### 1. ファイル構成の分離
ライブラリJS、CSS、アプリJSを分離しました。

### 2. デザインの改善
デザイントークンの導入、ボタンへのシャドウの付与などを行いました。

### 3. アクセシビリティの改善
セマンティックタグ化、ARIA属性整備、キーボード操作対応などを行いました。

### 4. JSロジック10ファイル分割
アプリJS を機能別に 10 ファイルに分割しました。

### 5. 不要なUIの削除
ヘッダーの**GPU ONLINE**と**MEM ok**表示、右パネル下部の **OUTPUT MODE**セクションなどを削除しました。
