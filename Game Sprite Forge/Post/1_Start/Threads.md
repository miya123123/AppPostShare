【Claude Opus 4.7】本モデルでツールを作りました。【スプライト差分画像生成ツール】

Claude Opus 4.7を初使用し、スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」を開発・公開しました。
入力したスプライト画像から、様々な差分画像を一瞬で量産できます。

差分画像とは、ベース画像の色やポーズ、表情などを変化させて作成した画像で、ベース画像との差異が極端に大きくない画像のことです。
本ツールでは毒状態、呼吸アニメーションなどの差分画像を生成可能です。

# 評価・所感
アルファ値の保持がされないなど、一部バグはありますが、プロンプト一つで本ツールを実装してくれました。
デザインも洗練されており、Claude Opus 4.7の優秀さを実感しました。
現在最強のLLMだと思います。
ローカル環境で差分画像を一瞬で量産できるため、アセット制作が捗るツールだと思います。
差分画像関連の知識も深まり、とても有意義でした。
