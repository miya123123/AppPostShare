【Game Sprite Forge】本ツールを開発開始しました【スプライト差分画像生成ツール】

スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」の開発を開始しました。
入力したスプライト画像から、後述の様々な差分画像を一瞬で量産できます。

差分画像とは、ベース画像の色やポーズ、表情などを変化させて作成した画像で、ベース画像との差異が極端に大きくない画像のことです。
本ツールでは毒状態、呼吸アニメーションなどの差分画像を生成可能です。
