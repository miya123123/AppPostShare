【Game Sprite Forge】アップデートを行いました。【スプライト差分画像生成ツール】

https://x.com/miya00907380/status/2050334453671526699

前回紹介した、スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」の以下の機能修正を行いました。

# 修正内容
### Damage関連のPIXEL FXの改善
Damageノイズの種類の選択肢を新規追加しました。
また、ノイズの種類と生成方法を以下のチェックボックス形式で選択できるようにしました。

- ノイズの種類: Transparent（透明）/ Blackout（黒・新規追加）/ White（白）/ None（ノイズなし・新規追加）
- ノイズの生成方法: Random（ランダム位置に生成）/ Dither（ディザリング手法で生成）

ノイズの種類と生成方法は独立して選択可能です。

# 今後の展望
### 1. 画像出力形式の追加
以下のPNG以外の画像形式の出力に対応させます。

- GIF / APNG / WebP（優先度大）
- Aseprite / Tiled / Unity Atlas（優先度小）

### 2. 生成できる差分画像の追加
生成できるエフェクトやアニメーションの差分画像を追加・強化します。

### 3. カスタムパレット読み込み機能の追加
ユーザー独自のカスタムパレットの読み込み機能を追加します。
パレットの形式としては、.hex（優先度大）/ .gpl / .pal を予定しています。

本機能の実装により、ユーザーが指定した独自の色への減色が可能になります。
（既存の `Snap to palette` 機能は64色への減色のみ対応しており、減色後の色も指定することはできません。）

### 4. 本ツールの出品
Boothなどで本ツールを出品します。

# 特徴
1. **🍄 ローカル環境で即座に生成とプレビューが可能:** 差分画像を一瞬でまとめて生成し、即座にプレビューできます。画像生成AIは一切使用せず、ピクセルのRGBA値を変更するアルゴリズムで画像生成します。ローカル・オフライン・無料で瞬時に生成可能です。
2. **⚡ 以下の10種類の差分画像生成に対応:**
  * Damage（ダメージ時の赤フラッシュ＋ノイズ）
  * Hurt Shake（ダメージ＋振動アニメーション）
  * Color Swap（パレットの色相シフト）
  * Idle Breath（待機時の呼吸アニメーション）
  * Blink（輝度の点滅）
  * Frozen（氷結時の青色オーバーレイ）
  * Poisoned（毒状態の緑色パルス）
  * Ghost（半透明＋青色シルエット）
  * Silhouette（黒塗りブロックアウト）
  * Burning（炎のエッジ＋赤熱エフェクト）
3. **⚙️ 細かなパラメータ調整:** ダメージの強度、色相のシフト数、呼吸のフレーム数や振幅をスライダーで直感的に調整可能です。
4. **🎨 ピクセルアート向けFX:** パレットのクオンタイズ（減色）、アウトラインの自動追加、Damage画像のノイズ処理を搭載しています。
5. **📦 スプライトシート一括書き出し:** 生成したすべての差分画像やアニメーションフレームを、1枚の巨大なスプライトシート（PNG）として一括エクスポート可能です。
