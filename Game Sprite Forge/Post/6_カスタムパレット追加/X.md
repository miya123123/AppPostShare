# 概要
スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」の開発記録です。
.hex形式のカスタムパレット読み込み機能の追加（優先度大）を完成させました。
これにより、任意の色で減色できるようになりました。
今後は、リファクタリングや軽微な修正、出品に向けた準備を行います。
