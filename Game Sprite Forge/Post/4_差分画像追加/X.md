【Game Sprite Forge（第四弾）｜スプライト差分画像生成ツール】差分画像を追加しました。

# 概要
スプライト差分画像を高速生成できるゲーム開発向けツール「Game Sprite Forge」の開発記録です。
生成できる差分画像の追加（優先度大）を行いました。
今後は、カスタムパレット読み込み機能などを追加し、Boothなどでの出品を予定しています。

# 作業内容
以下の差分画像（12種）の生成機能を追加（優先度大）しました。

* Charge（ためる）：黄白の同心リング3重が内側へ収束するアニメ
* Stunned（スタン）：頭上を星3つが等間隔で円軌道に回るアニメ
* Sleep（睡眠）：右上に "Z" が上昇しながら明滅するアニメ
* Confused（混乱）：頭上の "?" が左右に揺れ、本体の色相が±15°振動するアニメ
* Electrified（感電）：エッジ付近に白／水色の稲妻がランダムに走るアニメ
* Wet（濡れ）：全体を青味で乗算し、上半分に光沢ハイライトを加算する静止差分
* Petrified（石化）：グレースケール化＋暗部ノイズ＋わずかな茶色トーンの静止差分
* Invisible（透明化）：本体を15%まで透過、エッジのみ50%で輪郭を残す静止差分
* Levitate（浮遊）：本体が上下に±2px揺れ、足元の楕円影が連動して伸縮するアニメ
* Death Dissolve（消滅）：下から順にピクセルが消え、消滅直前に白くフラッシュするアニメ
* Spawn（出現）：Death Dissolveの逆再生で、組み上がった画素が一瞬白く光るアニメ
* Aura Ring（オーラ）：足元のシアン→青グラデの楕円リングが脈動するアニメ

差分画像の増加に伴い、生成する差分画像の一括選択・一括解除ボタンも併せて実装しました。

# 所感
ChargeとAura Ringには、リングが欠けている点などの改善余地があると感じました。
それ以外は、このまま採用して問題なさそうです。

# 今後の展望
### 1. スプライトシート出力形式の追加（優先度小）
以下の形式の出力に対応させます。
- Aseprite / Tiled / Unity Atlas

### 2. 追加差分画像の修正（優先度大）
- ChargeとAura Ringのリングが欠ける点を修正します。
- Chargeのデフォルトを中央収束に変更します。もしくは、足元収束もオプションとして残します。
- Aura Ringは、リングが広がるアニメーションから、一定サイズで脈動するアニメーションに変更します。
- アニメーション系の差分画像のフレーム数をパラメータで調整できるようにします。

### 3. カスタムパレット読み込み機能の追加
ユーザー独自のカスタムパレットの読み込み機能を追加します。
パレットの形式としては、.hex（優先度大）/ .gpl / .pal を予定しています。

これにより、独自に指定した色への減色が可能になります。
（既存の `Snap to palette` 機能は64色への減色のみで、減色後の色を指定することはできません。）

### 4. 軽微な機能修正（優先度大）
バグやUIに関する軽微な修正を行います。

### 5. 本ツールの出品（優先度大）
Boothなどで本ツールを出品します。
関連するドキュメント類の作成も行います。
