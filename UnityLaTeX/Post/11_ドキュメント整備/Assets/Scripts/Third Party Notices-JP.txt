本パッケージ独自の実装
======================

LaTeXからSVGへの出力は、本パッケージ独自のUnityLaTeX.Rendering.CSharpMathSvgBackendによって実装されています。公開されたCSharpMath.RenderingのICanvas APIへ直接接続し、別のグラフィックスバックエンドを使用せず、パスによるSVGを出力します。

削除済みの依存部品
==================

本パッケージには、以下は含まれず、使用もされていません。
  - VectSharp
  - VectSharp.SVG
  - CSharpMath.VectSharp
  - ExCSS
  - Unity Vector Graphics
  - MathJax HTTP API

LaTeXからSVGへの変換とSVGからPNGへの変換は、どちらもマネージドC#コードでローカルに実行され、実行時のネットワーク接続は不要です。
