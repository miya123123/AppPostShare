Package-owned implementation
============================

LaTeX-to-SVG output is implemented by the package-owned
UnityLaTeX.Rendering.CSharpMathSvgBackend. It connects directly to the public
CSharpMath.Rendering ICanvas API and emits path-based SVG without another
graphics backend.

Removed dependencies
====================

The package no longer includes or uses:
  - VectSharp
  - VectSharp.SVG
  - CSharpMath.VectSharp
  - ExCSS
  - Unity Vector Graphics
  - MathJax HTTP API

LaTeX-to-SVG and SVG-to-PNG conversion are both performed locally in managed
C# code and require no network connection at runtime.
