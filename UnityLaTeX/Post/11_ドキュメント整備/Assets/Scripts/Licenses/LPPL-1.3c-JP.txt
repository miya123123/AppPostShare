前文
====
LaTeX Project Public License（LPPL）は、LaTeXカーネルおよび基本LaTeXパッケージを配布する際の主要なライセンスです。ご自身が著作権を保有し、配布を希望する任意の著作物にこのライセンスを使用できます。TeXに関連する著作物（LaTeXパッケージなど）には特に適している場合がありますが、TeXと無関係の著作物にも使用できるように記述されています。

後述の「このライセンスに基づく著作物の配布の判断と方法」では、このライセンスによる著作物の配布を検討している著作者向けに、手順、例、推奨事項を示します。このライセンスは、著作物を配布・変更できる条件と、その変更版を配布できる条件を定めています。

私たちLaTeX3 Projectは、以下の条件によって、著作物の入手可能性、完全性、信頼性を維持しながら、希望する技術仕様に従う変更版を作成・配布する自由が得られると考えています。これらの条件を満たしつつ目的を達成する方法が分からない場合は、基本LaTeX配布物のcfgguide.texおよびmodguide.texをご参照ください。

定義
====
このライセンス文書では、以下の用語を使用します。

「著作物」（Work）
このライセンスに基づいて配布される任意の著作物です。

「派生著作物」（Derived Work）
適用される法律のいずれかにおいて、著作物から派生したとされる任意の著作物です。

「変更」（Modification）
適用される法律のいずれかにおいて派生著作物を生み出す任意の手続きです。例えば、著作物に関連する元のファイルまたはその相当部分を、そのまま、変更して、または他の言語に翻訳して含むファイルの作成が該当します。

「変更する」（Modify）
適用される法律のいずれかにおいて派生著作物を生み出す任意の手続きを適用することです。

「配布」（Distribution）
著作物の全部または一部の複製を、ある人から別の人へ入手可能にすることです。FTPやHTTPなどのファイル転送プロトコル、またはSunのNetwork File System（NFS）などの共有ファイルシステムによって、著作物の電子的な構成要素を利用可能にすることも含みますが、これらに限定されません。

「コンパイル済み著作物」（Compiled Work）
コンピューターシステム上で直接利用できる形式に処理された著作物の版です。この処理には、著作物が提供するインストール機能の使用、著作物の変換、構成要素のコピー、その他の作業が含まれる場合があります。著作物が提供するインストール機能を変更することは、著作物自体の変更に当たります。

「現保守者」（Current Maintainer）
著作物の中でそのように指定された人または人々です。明示的な指定がない場合は、適用される法律における「著作権者」です。

「基本インタープリター」（Base Interpreter）
著作物の全部または一部を実行または解釈するために通常必要となるプログラムまたは処理です。基本インタープリターは外部の構成要素に依存しても構いませんが、各外部構成要素が対話的に使用されるたびに自身を明確に識別する場合、それらは基本インタープリターの一部とはみなされません。著作物にライセンスを適用する際に明示的に指定されていない限り、適用される基本インタープリターはLaTeX-Formatのみです。ただし、LaTeX-formatに属するファイルの場合は、TeX言語を実装するプログラムです。

配布および変更に関する条件
==========================

1. 著作物の配布および／または変更以外の活動は、このライセンスの対象外です。特に、著作物を実行する行為は制限されず、著作物のサポートを申し出ることに関する要件もありません。

2. 受け取った著作物の完全な、変更されていない複製を配布できます。著作物の一部だけを配布することは著作物の変更とみなされ、そのような派生著作物を配布する権利がこの条項により認められると解釈してはなりません。

3. 上記第2条に基づいて配布された、著作物の完全な、変更されていない複製から生成したコンパイル済み著作物を配布できます。ただし、受領者が著作物から直接コンパイル済み著作物を生成した場合とまったく同じように、自分のシステムにインストールできる方法で配布しなければなりません。

4. 著作物の現保守者である場合、制限なく著作物を変更して派生著作物を作成できます。また、その派生著作物から生成したコンパイル済み著作物を含め、派生著作物を制限なく配布できます。現保守者がこの方法で配布した派生著作物は、著作物の更新版とみなされます。

5. 著作物の現保守者でない場合、自分が保有する著作物の複製を変更して派生著作物を作成し、その派生著作物をコンパイルして、派生著作物に基づくコンパイル済み著作物を作成できます。

6. 著作物の現保守者でない場合、著作物の各構成要素について以下の条件を満たすことを前提に、派生著作物を配布できます。ただし、その構成要素の著作権表示に、該当する条件が免除される旨が明記されている場合を除きます。この免除表示を著作物の構成要素に追加できるのは現保守者だけです。

  a. 派生著作物の構成要素が、基本インタープリターで使用される著作物の構成要素を直接置き換えられる場合、元の構成要素がその基本インタープリターによる対話的使用時に利用者へ自身を識別するすべての箇所で、派生著作物の置換構成要素も、その基本インタープリターによる対話的使用時に、元の構成要素の変更版であることを利用者に明確かつ曖昧さなく示さなければなりません。

  b. 派生著作物の各構成要素には、その構成要素への変更内容を詳述した目立つ通知、または完全で正確な変更記録を含み、派生著作物の一部として配布される別ファイルへの目立つ参照を含めなければなりません。

  c. 派生著作物内の情報は、元の著作物の著作者を含むいかなる人についても、その人が派生著作物のサポートを提供すると明示していない限り、派生著作物の受領者にサポートを提供すると示唆してはなりません。ここでサポートには、エラーの報告および対応が含まれますが、それらに限定されません。

  d. 派生著作物とともに、以下の少なくとも一方を配布しなければなりません。
    1. 著作物の完全な、変更されていない複製。
       変更した構成要素を指定の場所からコピーできるようにする方法で配布する場合、同じ場所または類似の場所から著作物をコピーするための同等のアクセスを提供すれば、この条件を満たします。第三者が変更した構成要素と一緒に著作物をコピーすることを義務付けられていなくても構いません。
    2. 著作物の完全な、変更されていない複製を入手するために十分な情報。

7. 著作物の現保守者でない場合、派生著作物から生成したコンパイル済み著作物を配布できます。ただし、コンパイル済み著作物のすべての受領者に派生著作物を配布し、その派生著作物について上記第6条の条件を満たさなければなりません。

8. 上記条件は、構成要素を、現保守者が上記第4条に基づいて配布する同じ構成要素の更新版と同一にするための、あらゆる方法による変更を禁止する意図はなく、そのような変更には適用されません。

9. 著作物または派生著作物を別の形式で配布し、その形式に何らかの処理を適用して著作物または派生著作物の全部または一部を生成する場合でも、その処理の結果に適用されるこのライセンスの条項が緩和されたり無効になったりすることはありません。

10. a. 派生著作物は、別のライセンスに基づいて配布できます。ただし、そのライセンス自体が、元の著作物について上記第6条の条件を守らなければなりません。このライセンスの残りの条件まで守る必要はありません。

    b. 派生著作物を別のライセンスに基づいて配布する場合、各受領者が、元の著作物からの変更に関する上記第6条の制限を守れるよう、派生著作物の一部として十分な文書を提供しなければなりません。

11. このライセンスは、著作物と無関係の著作物に制限を課しません。また、そのような著作物をどのような方法で本著作物とまとめることにも制限を課しません。

12. このライセンスのいかなる規定も、すべての当事者が適用されるすべての法律を完全に遵守することを妨げる意図はなく、そのような目的に利用することもできません。

無保証
======
著作物には保証がありません。書面に別段の記載がない限り、著作権者は著作物を「現状のまま」提供し、明示または黙示を問わず、商品性および特定目的への適合性の黙示の保証を含む、いかなる保証も行いません。著作物の品質および性能に関するすべてのリスクは利用者が負います。著作物に欠陥があることが判明した場合、必要な整備、修理、修正の費用はすべて利用者が負担します。

適用法により要求される場合、または書面による合意がある場合を除き、著作権者、著作物の構成要素に名が記載された著作者、または上記の許諾に従って著作物を配布および／または変更するその他の当事者は、著作物の使用または使用不能によって生じる損害について、利用者に対し責任を負いません。これには一般損害、特別損害、付随的損害、結果的損害が含まれ、データの喪失、データが不正確になること、著作物が他のプログラムと動作しないことにより誰かが被る損失なども含まれますが、これらに限定されません。著作権者、当該著作者、当該当事者が、そのような損害の可能性を知らされていた場合も同様です。

著作物の保守
============
著作権者が、著作物の主要な著作権表示の近くに、著作権者のみが保守できる旨、または単にauthor-maintainedである旨を明示的かつ目立つ形で記載した場合、著作物の保守状態はauthor-maintained（著作者による保守）です。

現保守者が存在し、著作物についてエラー報告を受け取る意思を著作物の中で示している場合（例えば、有効な電子メールアドレスを提供している場合）、保守状態はmaintained（保守中）です。現保守者には、そのエラー報告を受領したことを知らせたり、対応したりする義務はありません。

現保守者が存在しない場合、または現保守者とされる人に、記載された連絡方法で6か月間連絡が取れず、活発な保守を示すその他の重要な兆候もない場合、著作物の状態はmaintainedからunmaintained（未保守）に変わります。

既存の現保守者のいずれかと、この役割を引き継ぐことについて合意すれば、著作物の現保守者になることができます。
著作物が未保守の場合は、以下の手順で現保守者になることができます。

1. インターネットなどの検索手段を通じ、現保守者（著作権者が別人なら著作権者も）を探す合理的な試みを行います。

2. 検索に成功した場合、著作物が現在も保守されているかを問い合わせます。
  a. 保守されている場合、現保守者に対して1か月以内に連絡先情報を更新するよう求めます。
  b. 検索が不成功の場合、または現保守者が活発な保守を再開する行動を取らない場合、関連するコミュニティで保守を引き継ぐ意思を表明します。（LaTeXの著作物であれば、例えばcomp.text.texへの投稿で行えます。）

3a. 現保守者に連絡が取れ、保守を引き継ぐことに同意した場合、その公表と同時に引継ぎが有効となります。
  b. 現保守者に連絡が取れず、著作権者が保守の引継ぎに同意した場合、その公表と同時に引継ぎが有効となります。

4. 上記2bの「意思表明」を行い、その後3か月間、現保守者、著作権者、その他の人のいずれからも異議が出なかった場合、ご自身を新しい現保守者として記載するよう著作物を変更する手配を行えます。

5. 上記3bまたは4に基づく変更が完了してから3か月以内に、以前は連絡が取れなかった現保守者と再び連絡が取れるようになった場合、その人が要請し、かつ1か月以内に連絡先情報を更新することを条件として、その人が現保守者になる、または現保守者であり続ける必要があります。

現保守者の変更それ自体によって、著作物がLPPLに基づいて配布されるという事実は変わりません。

現保守者になった場合は、著作物の中に、ご自身が現保守者であることを目立つ形で曖昧さなく直ちに記載すべきです。また、上記2bと同じ関連コミュニティで、新しい地位を公表すべきです。

このライセンスに基づく著作物の配布の判断と方法
==============================================
この節は、このライセンスによる著作物の配布を検討している著作者に向けて、重要な手順、例、推奨事項を示します。この節の「あなた」は、それらの著作者を指します。

このライセンスと別のライセンスの選択
------------------------------------
著作物のどこかの部分について、このライセンスとは大きく異なる配布条件を使用したい、または使用する必要がある場合、著作物のどこにもこのライセンスを参照せず、代わりに別のライセンスで配布してください。このライセンスの文章を独自ライセンスのひな型に使用できますが、その独自ライセンスではLPPLを参照したり、著作物がLPPLで配布されているという印象を与えたりすべきではありません。

基本LaTeX配布物のmodguide.texは、このライセンスの条件の背景を説明します。例えば、LaTeXをGNU General Public License（GPL）で配布することが不適切と考えられた理由が説明されています。著作物がLaTeXと無関係であっても、modguide.texの議論が関連する場合があります。どのライセンスであれ著作物を配布しようとする著作者には、その文書を読むことを推奨します。

配布しない変更に関する推奨事項
------------------------------
個人的な使用であっても、著作物の構成要素を変更する際は、変更した構成要素を配布するための上記条件も満たしておくのが賢明です。そのような変更を配布しないつもりでも、偶然配布してしまうことはしばしばあります。変更したことを忘れる場合や、他者に変更版へのアクセスを認めることが配布に当たると気付かない場合があるためです。その結果、このライセンスの条件に違反して法的な影響が生じ、さらにコミュニティに問題をもたらす可能性があります。したがって、通常は自分の著作物の複製を公開版と同一に保つことが、ご自身の利益にかないます。多くの著作物は、ライセンスが適用される構成要素を変更せずに動作を制御する方法を提供しています。

このライセンスの使用方法
------------------------
このライセンスを使用するには、著作物の各構成要素に、ご自身の名前と、その著作物を作成した年および／または最後に実質的な変更を加えた年を含む明示的な著作権表示を記載してください。また、その構成要素の配布および／または変更が、このライセンスの条件によって制約される旨も記載してください。

以下は、そのような表示と声明の例です（参考訳）。
  %% pig.dtx
  %% Copyright 2008 M. Y. Name
  %
  % 本著作物は、LaTeX Project Public Licenseのバージョン1.3、
  % または（ご自身の選択により）それ以降のバージョンの条件に従って、
  % 配布および／または変更できます。
  % このライセンスの最新版は次にあります。
  %   https://www.latex-project.org/lppl.txt
  % バージョン1.3c以降は、2008年以降のすべてのLaTeX配布物に含まれています。
  %
  % 本著作物のLPPL保守状態はmaintainedです。
  %
  % 本著作物の現保守者はM. Y. Nameです。
  %
  % 本著作物はpig.dtx、pig.ins、および派生ファイルpig.styで構成されます。

このような表示と声明がファイルにある場合、このライセンス文書の条件が適用されます。「著作物」はpig.dtx、pig.ins、pig.styの3ファイルを指します（最後のファイルは、pig.insを使用してpig.dtxから生成されます）。「基本インタープリター」は任意のLaTeX-Formatを指し、「著作権者」と「現保守者」はいずれもM. Y. Nameという人を指します。

LPPLの保守に関する節を著作物に適用したくない場合は、上記のmaintainedをauthor-maintainedに変更してください。ただし、maintainedの使用を推奨します。保守に関する節は、ご自身が保守・サポートできなくなっても、著作物がコミュニティにとって有用であり続けることを確保するために追加されたものだからです。

置換を目的としない派生著作物
----------------------------
LPPLのいくつかの条項は、利用者コミュニティに信頼性と安定性を提供する手段を定めています。したがって、それらは派生著作物を、元の著作物の互換または非互換の置換として使用することを意図した場合を対象としています。そうでない場合（例えば、まったく別の作業のために数行のコードを再利用する場合）、第6条bおよび第6条dは適用されません。

重要な推奨事項
--------------

著作物を構成するものの定義
  LPPLは、著作物の配布物に、その著作物のすべてのファイルを含めることを要求します。したがって、どのファイルが著作物を構成するかを利用許諾を受ける人が判断できる手段を提供することが重要です。例えば、各ファイルの著作権表示の近くに著作物の全ファイルを明示的に列挙するか、同じ場所に次のような行を記載することで実現できます。
    % 本著作物はmanifest.txtに列挙されたすべてのファイルで構成されます。

  明確な一覧がないと、利用許諾を受ける人は、あなたが何を著作物に含むと考えているのか判断できない場合があります。その場合、その人には、どのファイルが著作物を構成するかについて合理的に推測する権利があります。
