【UnityLaTeX（第11弾）】ドキュメント整備を行いました。

【作業内容】
UnityでLaTeX数式を表示するツール「UnityLaTeX」の進捗報告です。
今回はUnity Asset Storeへの出品に向けた、以下のサードパーティ関連のライセンス文書の追加・修正を行いました。
コードは一切修正していません。

【追加・修正文書】
・Third Party Notices.txt
本ツールで利用しているTypography（フォント処理ライブラリ、MITライセンス）と、埋め込みフォント3種の名称、ライセンス、出典などを追加しました。フォントについては、ファイル名と著作権も追加しています。

・MIT-CSharpMath-Typography.txt
CSharpMathとTypographyに適用されるMITライセンス文です。両プロジェクトの著作権表示はこちらに記載されています。

・OFL-1.1.txt
Cyrillic Modern、AMS Capital Blackboard BoldフォントのSIL Open Font License 1.1のライセンス文です。

・GUST-FONT-LICENSE.txt
Latin Modern MathフォントのGUST Font Licenseのライセンス文です。

・LPPL-1.3c.txt
GUST Font License の中で参照されているLaTeX Project Public License 1.3cのライセンス文です。本ライセンス文の利用条件が参照され、Latin Modern Mathフォントの利用条件として使用されています。

【今後の展望】
Unity Asset Storeでの公開に向けて、提出用チェックリストに沿って、通知とライセンス文書の最終確認を進めます。
