# 【概要】
```
世界地図風の戦場で、青・赤・黄の3勢力が天下統一を争うリアルタイム陣取り戦略シミュレーションゲームです。
プレイヤーは青勢力を操り、自国のユニットを隣国へ送ります。赤と黄のAI勢力を退けながら全領土の制圧を目指します。
中立国も含めた全ての国を占領するとステージクリアとなります。
3ステージ制であり、後半のステージほど難易度と獲得スコア（タイムボーナス）が高くなります。
```

# 【ルールと操作方法】
```
# ゲームの特徴
- 青のプレイヤーと、赤・黄の2つのAIが同時に領土を広げる3勢力戦
- 国の形状がプレイごとに変化する自動生成マップ
- タップのみで、隣国へ進軍・合流できる直感的な操作
- 初期配置と敵戦力が変化する全3ステージ
- 領土、敵国占領、被奪、クリアタイムを評価するスコアとS〜Cランク

# 遊び方
1. タイトル画面をタップまたはクリックしてゲームを開始します。
2. ユニットがいる青の自国を選びます。
3. 選んだ国と接する隣国をタップします。
4. 中立国や敵国を占領して青の領土を広げ、赤と黄の進軍を防ぎます。
5. すべての国を青勢力にするとステージクリアです。ステージ3を制覇すると全ステージクリアになります。

青の占領済み領土が0国になると敗北です。固定の制限時間はありませんが、早く制覇するほどタイムボーナスが高くなります。

# 操作方法
- ゲーム開始 | タイトル画面をタップ
- 移動元の選択 | ユニットがいる青の国をタップ
- 隣国へ進軍 | 移動元を選択後に隣国をタップ
- 戦力の合流 | 青の国から隣接する青の国へ移動

# 進軍と戦闘のルール
- 進軍できるのは、移動元と直接接している国だけです。
- 移動元のユニットは全て移動し、移動後の国は0ユニットになります。
- 味方の国へ移動するとユニットが合流します。
- 攻撃側のユニットが多ければ、約1秒かけて占領します。
- 占領中の国へは、どの勢力も移動できません。
- 中立以外の国は、5秒ごとに1ユニット増加します。

# スコア
- 持ち越しスコア | 前ステージの最終スコア
- 領土スコア | クリア時の青領土1国につき+200点
- 敵国占領ボーナス | 赤または黄の国を占領するたびに+200点（領土スコアと合わせ、占領時は実質+400点表示）
- 被奪ペナルティ | 青の国を敵に奪われるたびに-300点
- タイムボーナス | `max(500, floor(10000 - 経過秒 × 40)) × ステージ倍率`を整数化

# ステージ倍率
ステージ1〜3の順に1, 2.5, 10となります。

# ランク

- A | 9,500点以上12,000点未満
- B | 7,000点以上9,500点未満
- C | 7,000点未満
```
