# Prompt


# 【概要】
青・緑・赤・黄・ブラックの最大5勢力が領土を奪い合うリアルタイム陣取りストラテジーゲームです。

プレイヤーは **青軍** を操作し、隣接する国へユニットを進軍させて領土を拡大します。
自国への合流、同盟国への駐留、敵国・中立国への攻撃を使い分け、全国の完全制圧を目指します。

本作は、前作「ワールドテリトリー：3勢力陣取り合戦」の続編です。
同盟システムの追加、敵AIの強化、新勢力（緑・黒）の追加などのアップデートを行いました。
前作と比較し、難易度が大きく向上し、より手応えのあるゲームに仕上がったと思います。

ステージ3では4勢力が共闘して強力なブラック軍に立ち向かう協力決戦が待っています。

# 【ルールと操作方法】
# 遊び方
1. スタート画面をタップしてゲームを開始します。
2. ユニットがいる青軍の領土を選びます。同盟領に青軍が駐留している場合は、その領土も選択できます。
3. 隣接する領土をもう一度タップします。
4. 中立領や敵領を確保しながら戦線を広げ、青軍と同盟軍に敵対する全領土をなくすとステージクリアです。

# 前作からの主な変更点
前作『ワールドテリトリー：3勢力陣取り合戦』から勢力数・同盟システム・AI・難易度・スコアシステムなどが追加・強化されています。

| 比較項目 | 前作 | 本作 |
|---|---|---|
| 参加勢力 | 青軍、赤軍、黄軍の3勢力 | 青軍、緑軍、赤軍、黄軍の4勢力に加え、ステージ3限定のブラック軍が登場 |
| 同盟 | 同盟なし。全勢力が互いに敵対 | ステージごとに同盟関係が変化。青×緑、赤×黄、最終的には四軍同盟を実装 |
| AI | 赤軍と黄軍が約7秒間隔で単純な拡張行動 | 緑・赤・黄・ブラック軍が戦力差、前線、援軍、同盟、攻撃対象の価値を評価して行動 |
| 難易度 | 比較的簡単 | ステージ2とステージ3が高難易度 |
| 自動増援 | 5秒ごとに+1、通常上限100 | 4秒ごとに通常勢力+1、ブラック軍+2、通常の成長上限150 |
| スコア | ステージ2, ステージ3のタイム倍率は2.5倍, 10倍。 | ステージ2, 3のタイム倍率を5倍, 30倍へ変更し、20,000点・50,000点のステージクリアボーナスを追加 |

# ステージ構成
| ステージ | 青軍の初期状況 | 主な敵・同盟関係 | 特徴 |
|---|---|---|---|
| 1 | 右下の1領土・5ユニット | 青×緑、赤×黄の二組同盟 | 四隅から各勢力が拡大する基本ステージです。青軍は緑軍と協力して赤黄同盟を攻略します。 |
| 2 | 中央左寄りの1領土・5ユニット | 赤×黄のみ同盟。青・緑は独立勢力 | 赤軍と黄軍は各3領土・各25ユニット、緑軍は3領土・各5ユニットで開始します。青軍は単独で全勢力を制圧します。 |
| 3 | 左下の1領土・5ユニット | 青×緑×赤×黄の四軍同盟 対 ブラック軍 | 四軍は四隅から進軍します。ブラック軍は7拠点（50ユニットx6, 10ユニットx1）で開始します。 |

マップの領土形状は各プレイ開始時にランダムに再生成されます。
ブラック軍は通常勢力より高頻度で行動し、戦力の増加量も多く設定されています。

# ゲーム攻略のコツ
素早く自国の領土数を増やし、敵国の領土数を減らすことを目指しましょう！
