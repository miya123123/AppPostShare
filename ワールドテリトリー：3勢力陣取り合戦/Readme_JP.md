# ワールドテリトリー：3勢力陣取り合戦

35の国で構成された世界地図風の戦場で、青・赤・黄の3勢力が天下統一を争うリアルタイム陣取り戦略シミュレーションゲームです。

プレイヤーは青勢力を操り、自国のユニットを隣国へ送ります。中立国を占領し、味方の国で戦力を合流させ、赤と黄のAI勢力を退けながら全領土の制圧を目指します。

## ゲームの特徴

- 青のプレイヤーと、赤・黄の2つのAIが同時に領土を広げる3勢力戦
- 35の国の形とつながり方がプレイごとに変化する自動生成マップ
- タップまたはドラッグ＆ドロップで、隣国へ進軍・攻撃・合流できる直感的な操作
- 全ユニットを一度に送るため、攻める順番と国境の守りが重要になる戦力管理
- 初期配置と敵戦力が変化する全3ステージ
- 領土、敵国占領、被奪、クリアタイムを評価するスコアとS〜Cランク
- ブラウザに保存されるハイスコアと、DreamCore経由の結果シェア
- 日本語、英語、中国語、韓国語、スペイン語、ポルトガル語の6言語表示

## 遊び方

1. タイトル画面をタップまたはクリックしてゲームを開始します。
2. ユニットがいる青の自国を選びます。
3. 選んだ国と接する隣国をタップするか、自国から隣国へドラッグします。
4. 中立国や敵国を占領して青の領土を広げ、赤と黄の進軍を防ぎます。
5. 35の国すべてを青勢力にするとステージクリアです。ステージ3を制覇すると全ステージクリアになります。

青の占領済み領土が0国になると敗北です。固定の制限時間はありませんが、早く制覇するほどタイムボーナスが高くなります。

## 操作方法

| 操作 | タッチ・マウス |
| --- | --- |
| ゲーム開始 | タイトル画面をタップ／クリック |
| 移動元の選択 | ユニットがいる青の国をタップ／クリック |
| 隣国へ進軍 | 移動元を選択後に隣国をタップ／クリック |
| ドラッグで進軍 | 青の国から隣国へドラッグ＆ドロップ |
| 戦力の合流 | 青の国から隣接する青の国へ移動 |

ステージ1では、移動元と移動先を案内するチュートリアルが最初の2回ずつ表示されます。

## 進軍と戦闘のルール

- 進軍できるのは、移動元と直接接している国だけです。
- 移動元のユニットは全て移動し、移動後の国は0ユニットになります。
- 味方の国へ移動するとユニットが合流します。合流後の上限は999ユニットです。
- 中立国または敵国に進攻すると、攻撃側と守備側のユニットが同数ずつ減ります。
- 攻撃側のユニットが多ければ、残ったユニットで約1秒かけて占領します。
- 両者が同数ならユニットはどちらも0になり、攻撃側が少なければ守備側の残数が国に残ります。
- 占領進行中の国へは、どの勢力も追加で移動できません。
- 占領済みの中立以外の国は、5秒ごとに1ユニット増加します。通常の増加上限は100ユニットです。

## ステージ構成

| ステージ | 青勢力の開始状態 | 赤・黄勢力の開始状態 | タイムボーナス倍率 |
| ---: | --- | --- | ---: |
| 1 | 1国・5ユニット | 各1国・5ユニット | 1倍 |
| 2 | 1国・5ユニット | 各1国・100ユニット | 2.5倍 |
| 3 | 中央の1国・5ユニット | 赤は上側の3国、黄は下側の3国・各国100ユニット | 10倍 |

ステージを進むと、直前のステージの最終スコアを次のステージへ持ち越します。

## AI勢力

- 赤勢力は約7秒ごとに行動し、進攻候補の中から周囲と接する国が多い場所を優先します。
- 黄勢力は約7.5秒ごとに行動し、進攻可能な国からランダムに目標を選びます。
- どちらのAIも、目標に隣接する自国のうち、最もユニットが多い国から全戦力を送ります。

## スコアとランク

ステージクリア時の最終スコアは、次の要素で計算されます。

| 要素 | 計算方法 |
| --- | --- |
| 持ち越しスコア | 前ステージの最終スコア |
| 領土スコア | クリア時の青領土1国につき+200点 |
| 敵国占領ボーナス | 赤または黄の国を占領するたびに+200点（領土スコアと合わせ、占領時は実質+400点表示） |
| 被奪ペナルティ | 青の国を敵に奪われるたびに-300点 |
| タイムボーナス | `max(500, floor(10000 - 経過秒 × 40)) × ステージ倍率`を整数化 |

ゲーム中の表示スコアは0点未満にはなりません。敗北時の最終スコアは0点です。

| ランク | 最終スコア |
| --- | ---: |
| S | 12,000点以上 |
| A | 9,500点以上12,000点未満 |
| B | 7,000点以上9,500点未満 |
| C | 7,000点未満 |

ハイスコアはブラウザの `localStorage`（保存キー: `dreamcore_territory_high_score`）に保存されます。

## 攻略のヒント

- 自国を選んだ後に表示される点線と水色の強調表示で、進軍可能な隣国を確認しましょう。
- 攻撃後の移動元は0ユニットになるため、敵と接する国からむやみに全戦力を移さないことが大切です。
- 味方領土への合流で戦力を集め、守備ユニットより1以上多いユニットで攻めると占領できます。
- 赤勢力は接続の多い国を狙いやすいため、交通の要所となる領土は厚めに守ると安定します。
- 固定の制限時間はないため、苦しい場面では5秒ごとの自動増員を待つ選択も有効です。

## 実行について

本ゲームはビルド不要のHTML5ゲームです。ローカルで静的ファイルを配信する場合は、プロジェクトルートで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

起動後、`http://localhost:8000/HTML/index.html` を開きます。ただし、ゲームの開始、リトライ、ステージクリア通知、結果シェアなどは `DreamCoreSDK2`を直接参照しているため、完全なプレイには同SDKを提供するDreamCore実行環境が必要です。
