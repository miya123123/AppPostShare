# 概要
「ワールドテリトリー2：多勢力陣取り合戦」を公開しました。
青・緑・赤・黄・ブラックの最大5勢力が領土を奪い合うリアルタイム陣取りストラテジーゲームです。
プレイヤーは **青軍** を操作し、隣接する領土へユニットを進軍させて領土を拡大します。
自軍領への合流、同盟領への駐留、敵領・中立領への攻撃を使い分け、青軍と同盟軍による全領土の制圧を目指します。
ステージ3では青・緑・赤・黄の4勢力が共闘して強力なブラック軍に立ち向かう協力決戦が待っています。

ご興味のある方はぜひプレイしてください。
