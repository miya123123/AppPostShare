# Walkthrough: DD Timeline Promo Copy Edit

## Goal

Proofread the DreamCore timeline announcement for *World Territory: 3-Faction Battle* so it reads naturally, stays factually aligned with the game, and keeps the author's voice.

## Source of truth

1. `HTML/index.html` — in-game title, win/lose copy, stage language
2. `Readme_JP.md` — public rules, 3-stage structure, score multipliers
3. `memo.md` — original DD timeline draft
4. Sibling game `memo.md` files — house style for DD announcements

## Observed house style

- Open with `「[title]」を公開しました。`
- Describe the fantasy in one or two short sentences
- Add one concrete player action or hook
- Close the product block with `ご興味のある方はぜひプレイしてください。`
- Keep personal notes after the product pitch when the author wants them

## Edit path

1. Read the live draft in `memo.md`
2. Confirm later stages are harder and award more score (time-bonus multipliers 1 / 2.5 / 10)
3. Confirm the player commands the blue faction against red and yellow AI
4. Fix stiff copulas (`であり`) and the stacked modifier `昔断念した作りたかった`
5. Add one missing hook: play as blue, aim for unification
6. Remove the trailing full-width space after the bow emoji
7. Write the corrected copy back to `memo.md`
