# Walkthrough: DDタイムライン宣伝文の校正

## 目的

『ワールドテリトリー：3勢力陣取り合戦』のDreamCoreタイムライン宣伝文を、事実と一致させつつ、作者の声を残した自然な日本語へ整える。

## 一次情報

1. `HTML/index.html` — ゲーム内タイトル、勝敗文言、ステージ表現
2. `Readme_JP.md` — 公開用ルール、3ステージ構成、スコア倍率
3. `memo.md` — 元のDDタイムライン原稿
4. 他作品の `memo.md` — DD宣伝文の型

## 確認した型

- 冒頭は `「[タイトル]」を公開しました。`
- 世界観を1〜2文で示す
- プレイヤーが何をするかを1文入れる
- 紹介の締めは `ご興味のある方はぜひプレイしてください。`
- 開発所感は、必要な場合だけ紹介の後に置く

## 作業手順

1. `memo.md` の原稿を読む
2. 後半ステージほど難易度とスコア（タイムボーナス倍率 1 / 2.5 / 10）が上がることを確認する
3. プレイヤーが青勢力、敵が赤・黄のAIであることを確認する
4. 「であり」の硬さと、「昔断念した作りたかった」の修飾のねじれを直す
5. 青勢力操作と天下統一の目標を1文だけ補う
6. お辞儀絵文字の後ろの全角スペースを除く
7. 校正後の文を `memo.md` へ戻す

## 成果

校正後の宣伝文は、`memo.md` の `# DDタイムライン宣伝文` にあります。
