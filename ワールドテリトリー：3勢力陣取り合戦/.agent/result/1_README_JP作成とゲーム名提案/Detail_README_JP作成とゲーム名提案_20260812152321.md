- 仮想解像度: 390 × 844

- 勢力: プレイヤーの青、AIの赤と黄、中立の白

### 入力と戦闘

- マウスとタッチに対応
- 移動元を選択してから移動先を選ぶ2タップ方式
- 移動元から移動先へ直接ドラッグする方式
- 移動では移動元の全ユニットを使用
- 味方領土への移動でユニットを合流、上限999
- 敵領土・中立領土とは差し引きで戦闘処理
- 攻撃側が多い場合のみ占領開始、占領時間は約1秒
- 占領中の国は全勢力の移動対象外
- 占領済みの非中立領土は5秒ごとに+1ユニット、通常上限100

- ステージ数: 3
- ステージ1: 各勢力1国、初期5ユニット
- ステージ2: 青1国5ユニット、赤と黄は各1国100ユニット
- ステージ3: 青は中央1国5ユニット、赤は上側3国、黄は下側3国で各国100ユニット

- 敗北: 青の占領済み領土が0国
- 固定時間制限: なし
- ステージ間で最終スコアを持ち越し

4. 現在のHTMLに表示されるデバッグボタンを、通常操作と混同しないよう開発用UIとして別節に記載する。
5. `DreamCoreSDK2` がフォルダ内のJavaScriptファイルとして存在しないため、ローカルHTTPサーバーだけで完全プレイできると断定しない。
