# Implementation Plan: DDタイムライン宣伝文の校正

## 範囲

文章校正のみ。ゲーム本体、画像、`Post/` 配下のSNS原稿は変更しない。宣伝文そのものは `memo.md` を更新する。報告書と計画ファイルは `.agent/` に追加する。

## 制約

- AIとDreamCoreへの謝辞は残す
- 定型の「ご興味のある方はぜひプレイしてください。」は残す
- HTML / README にない仕様は書かない
- GitHubへはpushしない

## 手順

1. 原稿を `Readme_JP.md` とゲーム内文言と照合する
2. 書き直しではなく、軽い校正にする
3. 採用文を `memo.md` に保存する
4. 修正前後と理由を結果報告書へ残す
5. ローカルでcommitする

## 採用した言い換え

| 問題 | 判断 |
| --- | --- |
| `3ステージ制であり` | `全3ステージで` |
| `難易度と獲得スコア` | `難易度も獲得スコアも` |
| プレイヤー役割が無い | 青対赤・黄AI、天下統一を1文追加 |
| `昔断念した作りたかった` | `昔は作りたかったけれど断念した` |
| `ゲームであり` | `ゲームで` |
| 末尾の全角スペース | 削除 |

## 対象外

- `Post/X.md` など他SNS原稿の書き直し
- ゲーム名の変更
- 収録動画やサムネイル作業
