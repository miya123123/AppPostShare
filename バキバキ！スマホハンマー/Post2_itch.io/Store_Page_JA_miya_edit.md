# 概要
画面の中のスマホをハンマーで叩いて壊す、30秒のスコアチャレンジゲームです。
タップの連打で次々とスマホを破壊し、ハイスコアを目指します。
通常スマホは12打で全壊。ラウンド中には、通常の4倍の耐久を持つ「全面ガラスコーティング」のボスが登場することもあります。
限られた時間でボス撃破の大きなボーナスを狙うか、見送って通常スマホの破壊を続けるかはプレイヤー次第です。
この作品はMVPです。

# 遊び方
- タップ・クリックでハンマー打撃。最初の打撃から30秒チャレンジが始まります。
- 通常スマホは12打で全壊し、1秒の破壊演出後に次の通常スマホが登場します。
- 残り7秒以上・15秒以下で、通常スマホの破壊演出終了時に出現条件を満たすと、全面ガラスコーティングのボスが1回登場します。通常の4倍、48打で撃破できます。
- ボスへの挑戦は見送ることもできます。見送りは破壊台数として数えません。
- ボス撃破後・見送り後には通常スマホが再登場します。
- 終了時に破壊台数・打撃数・ボス撃破の結果を表示します。
- 「もう一度」「最初から」で新しいラウンドを始められます。

# スコア
- 有効な打撃1回: +10点（通常・ボス共通）
- 通常スマホの破壊: +150点のボーナス
- ボス撃破: +1,000点のボーナス
- 画面上部と終了時にスコアを表示します。

# ボスに挑戦するリスクとリターン
- リスクは、倒しきれないと、見送って通常スマホを複数破壊する場合より獲得スコアが小さくなる可能性があることです。
- リターンは、撃破時に、大きなボス撃破ボーナスが得られることです。
