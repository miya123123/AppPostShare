# EVERGREEN — プロシージャル・クリスマスツリー

枝葉・雪・装飾・電飾・星を調整し、ゲーム用3Dツリーを生成するブラウザツールです。Three.js r180を同梱しており、実行時のCDN接続は不要です。

## 主な機能

- 段数、高さ、広がり、積雪量、葉色の調整。
- ボール・星・プレゼント・ミックスと装飾密度、配色。
- ウォーム・マルチ・アイス・オーロラの電飾、光量と動き。
- 常灯・点滅・きらめき・ウェーブの4パターンと0.5〜2.0倍の速度調整。電球と光のハローを同期。
- 5角・8角・クリスタル・なしの頂点パーツ。
- 4つのプリセット、ランダム生成、シードによる配置の再現。
- 回転・ズーム・平行移動・キーボード操作・プレビュー拡大。
- PNG／GLB／JSON書き出しとJSON読込、端末への自動保存。

## 出力仕様

GLBはツリー本体のみです。プレビュー用の台座・プレゼント・背景・降雪・光のハローは含めません。Y-up、単位はm、接地中心が原点、正面は+Zです。幹・葉・雪・装飾・コード・電球・頂点の星を名前付きグループに分離しています。電飾の点滅はプレビューのみです。

PNGは保存時点の点滅状態を記録します。設定JSONはパターンと速度を保持し、速度項目のない旧ファイルは1.0倍として読み込みます。端末のアニメーション軽減設定が有効な場合、プレビューは常灯になります。

電球のプレビューはインスタンス描画、ハローはポイント描画でまとめています。毎フレーム更新するのは電球ごとの明るさのみで、パターン・速度・光量の変更時にツリー形状を再生成しません。GLB書き出し時は静的な電球モデルを使用します。

Unityに読み込む際はglTF対応インポーターを使用してください。発光や金属の見た目はゲーム側のライト・環境設定にも依存します。

## 実行と検証

`dist/`を静的Webサーバーで配信します。ES Modulesを使用するため、HTMLの直接ファイル起動ではなくHTTP配信が必要です。

`npm test`で設定の検証、境界値、全プリセット、形状の再現性、非表示パーツ、GLBのバイナリ構造とメタデータを検証します。ビルド処理は不要です。

外部ライブラリのライセンスは`dist/vendor/THREE-LICENSE.txt`です。アドオンのThree.js参照のみ、同梱ファイルを参照する相対パスに変更しています。

## 追加された調整機能

- プレビュー上部固定、画面内の開閉式表示設定、台座ON/OFF、自動回転速度0.1〜3.0倍。
- 高さ2.5〜7mを縦方向だけに反映。枝の広がりと飾りサイズは独立します。
- 幹の高さ5〜40％。全体の高さを保ち、枝葉の高さ配分を変更します。
- 天辺の飾りと枝のオーナメントは各50〜200％。
- 台座OFF時は幹の根元に地面を合わせ、下から見上げるカメラに対応。
- 表示設定の外側をタップすると閉じます。ドラッグ・ピンチ・設定内の操作と区別します。

## ローカルでの起動手順

1. ZIPを展開します。
2. 展開したフォルダで `python3 -m http.server 8000 --directory dist` を実行します。
3. ブラウザで http://localhost:8000 を開きます。

Python 3は配信用です。ツール自体は静的HTML/CSS/JavaScriptで動きます。WebGLに対応したブラウザをご利用ください。自動テストにはNode.jsを使用し、展開したフォルダで `npm test` を実行します。

## ファイル構成

- `dist/index.html` / `styles.css`: 画面とスタイル。
- `dist/app.js`: UI、プレビュー、保存・出力処理。
- `dist/tree-config.mjs`: 設定値、範囲、プリセット。
- `dist/tree-model.js`: ツリーのプロシージャル生成。
- `dist/light-animation.mjs`: 電飾アニメーション。
- `dist/preview-interactions.mjs`: プレビューのタップ判定。
- `dist/vendor/`: Three.jsと関連アドオン、ライセンス。
- `tests/`: 自動テスト。

GLBに影・床・台座は含まれません。読み込み先でライトと影を設定してください。3D表示とライティングの目視確認には、従来の検証環境でWebGL制限がありました。
