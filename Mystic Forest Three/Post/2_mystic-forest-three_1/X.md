【agent-sprite-forge】RPGの3D森フィールドを生成しました。【Codex】

# 作業内容
Codexとagent-sprite-forgeを使用し、プレイヤーが歩き回れるRPG風の3D森フィールドを生成しました。

npakaさんの記事を参考に、後述のプロンプトで生成しました。

プロンプト一発で完成したわけではなく、まずベースとなるフィールド画像を生成し、それを元に3Dフィールドを生成しました。
その後、テクスチャや物理挙動、キャラクターの移動方法などを修正しました。

プレイヤーの歩行アニメーション画像はagent-sprite-forgeで、テクスチャなどはImage Genで生成しました。

# 結果・所感
動画のように、なかなかの品質の3D森フィールドを生成してくれました。
横視点での歩行アニメーションに不自然な点はあります（足が動いていない）が、キャラクターやカメラは概ね自然にスムーズに動かすことができるという印象です。
agent-sprite-forgeとCodexを組み合わせれば、2.5Dゲームもバイブコーディングで作れそうです。

# 使用したプロンプト
### 1. フィールド画像の生成
```
$imagegen ローポリのゲーム画面の神秘の森をアイソメトリック視点で描いてください。
ステータスウィンドウなどはなしでお願いします。
```

### 2. フィールド画像を元にした3Dフィールドとテクスチャの生成
```
@game.png を元に、ローポリボクセルの神秘の森を、Vite + TypeScript + Three.jsで作ってください。
テクスチャを $imagegen で生成して貼り付けてください。
```

### 3. クリスタルのテクスチャの修正
```
@game2.png 発光クリスタル（水色と紫）のテクスチャがおかしいです。 $imagegen で再度生成して貼り付けてください。
```

### 4. キノコのテクスチャの修正
```
@game3.png 
キノコのピンク単色のテクスチャを $imagegen で再度生成して貼り付けてください。
```

### 5. キノコのテクスチャの修正2
```
キノコのテクスチャがイマイチです。別バージョンを $imagegen で作り直してください。
```

### 6. キャラクターの歩行アニメーションの生成と移動処理の実装
```
キャラクターの歩行アニメーションを $generate2dsprite で生成してください。ビルボード視点でお願いします。そして、本ゲームの中に配置し、移動できるようにしてください。
```

### 7. 歩行アニメーションと移動処理の修正
```
ビルボード視点はやめてください。
キャラクターの歩行アニメーションを斜め右上、斜め右下、斜め左上、斜め左下のパターンも $generate2dsprite で生成し、画面の角度に応じて上下左右の画像と切り替えるようにしてください。
マップの回転といっしょにキャラクターも回転(スプライト画像の選択で表現)するようにしてください 。
```

### 8. キャラクターが浮いている問題の対処
```
@game4_1.png
@game4_2.png
キャラクターが浮いている問題に対処してください。
```
