【GPT-6 Astra】倒した敵が仲間になるシューティングゲームを開発【FOE TO FLEET】

【作業内容】
GPT-6 Astraを使用し、倒した敵が仲間になる弾幕シューティングゲーム「FOE TO FLEET」のMVPを開発・公開しました！
約2分でクリア可能な短時間型ゲームです。
仲間は敵を撃つ「武器」にも、敵弾を受け止める「盾」にもなります。
敵の時の能力（武器と最大HP）が引き継がれるため、強敵を倒すほど艦隊が強化されます。

【結果・所感】
敵を仲間に変え、武器や盾として活用しながら、弾幕を乗り切るシステムは斬新でとても面白いと感じます。
今後、ボスの実装やUI/UXの洗練などの肉付けを施せばより面白くなるかもしれません。

【使用技術】
・Codex (gpt-6-astra): メイン機能の設計・実装、サブ機能の設計
・Codex (gpt-5-luna): サブ機能の実装
・React / TypeScript / Vite: アプリ実装・開発サーバー
・Canvas 2D / Web Audio API: 描画・効果音
・Tailwind CSS: UI
・Playwright: 自動テスト
・game-ui-designスキル、game-ui-uxスキル: UI/UXの洗練

【今後の展望】
1. ボスの実装
2. 仲間の加入方式の拡張
現状は仲間が満員時（最大12機）は仲間が加入されません。仲間が撃退され欠員発生後、新たに倒した敵が加入される方式となっています。
これを修正し、満員時に倒したより強い敵と既存の仲間を入れ替える、あるいは満員時に倒した敵をストックし欠員が出た場合にストックから即座に補充する方式に変更することを試します。

3. UI/UXの洗練
エフェクト・HUD・サウンド・アニメーションなどを追加・修正し、プレイヤーがより心地よい体験ができることを目指します。
