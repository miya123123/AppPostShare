75秒・1920×1080・30fpsの横長MP4です。日本語字幕を映像に焼き込み、音声は収録していません。PCの生成操作、実機スマホでの固定プレビュー、現行版の3スタイルと書き出しを紹介します。

## 再制作

プロジェクトのルートから実行します。Node.js、既存のローカルPlaywright、Google Chrome、FFmpeg/ffprobe、Python 3とPillowが必要です。元の録画3本と、現行版の `src/floating-island-workshop/dist` を用意してください。

1. 別ターミナルで `python3 -m http.server 8765 --bind 127.0.0.1 --directory src/floating-island-workshop/dist` を起動します。
2. `node Post/紹介動画/record.mjs` で追加撮影と3形式のダウンロードを行います。
3. `python3 Post/紹介動画/edit.py` で字幕付きMP4を作成します。
4. `python3 Post/紹介動画/verify.py` で全編デコード、動画仕様、保存ファイルを検証します。
5. `output/playwright/intro/review-*.png` の代表フレームを目視し、字幕・構図・操作の見え方を確認します。
6. HTTPサーバーをCtrl+Cで停止します。撮影スクリプトは終了時に専用ブラウザを閉じます。

macOSのChromeで録画領域の下端が欠けたため、専用ウィンドウの外枠を1920×1167へ調整しています。ページと出力映像は1920×1080です。環境を変える場合は灰色の余白や欠けがないことを確認してください。書き出しカットのみ、ブラウザの通常ズーム相当の縮小を撮影時に適用しています。ツールの生成ロジックは変更していません。

## 検証の範囲

機械検証と目視確認は分けます。全2250フレームのデコード成功は動画ファイルの健全性を示し、映像品質の目視を代替しません。代表35フレームの確認では各カット、設定の変化、字幕、スマホの並列表示、出力ボタン、PNG、最終画面を確認します。全フレームを連続して目視したという意味ではありません。

GLBはヘッダー・チャンク・バッファ範囲・メッシュ・材質・神殿を確認します。JSONは設定・3島・2橋・神殿・地表・開始地点を確認します。PNGは実際の復号、寸法、画像が単色でないことを確認します。ゲームエンジンへの取り込みは今回の紹介範囲に含めていません。
