# 紹介動画の目視確認

Codexによる代表35時点の確認記録です。全2250フレームの連続目視とは区別します。全編デコードの結果は `verification.json` に記録しています。字幕の書き出しタイミングを調整した最終版では、変更範囲と最終画面を改めて確認しました。

| 範囲 | 確認内容 | 観察 |
| --- | --- | --- |
| 0〜6秒 | タイトル・景観・導入字幕 | 日本語が描画され、タイトルと字幕は切れていません。群島・橋・滝が確認できます。 |
| 6〜18秒 | 3スタイル | 緑・夜・雪の違いが見え、スタイル名と景観が一致しています。 |
| 18〜34秒 | PC操作 | 島数による群島の変化、岩形状の選択、神殿の追加が見えます。設定操作の場面では、対象の島と操作欄を優先しています。 |
| 34〜42秒 | 拡大・回転・ズーム | 視点が変化し、神殿・橋・滝を含む景観を確認できます。ズーム時は近景の一部が画面端に寄ります。 |
| 42〜58秒 | 実機スマホ | 固定スイッチがONで、設定欄のスクロールと生成結果の変化が見えます。左右のプレビューは同一時刻の映像です。岩形状の選択中には、実機の選択メニューと通常の暗転表示が映ります。 |

| 70〜75秒 | 終了画面 | 景観、ツール名、素材制作の用途が確認できます。 |
